# 🗺️ Roadmap & Tahapan Pengembangan Fitur

## 📌 Fase 1: MVP (Minimum Viable Product) - Wajib Ada
* [x] Kanvas game 2D responsif yang menyesuaikan layar HP dan layar desktop secara otomatis.
* [x] Model dump truck kartun dengan animasi roda berputar dan bodi berguncang (*physics bounce*).
* [x] Sistem pengisian muatan pasir/batu permen warna-warni (Loading Station).
* [x] Sistem berkendara: tombol Gas (Maju), Rem (Mundur), dan jalanan berbukit dengan koin bintang.
* [x] Tombol Klakson Telolet / Basuri dengan efek nada ceria.
* [x] Sistem jungkit muatan (Dump Station) dengan selebrasi partikel konfeti.
* [x] Efek suara sintetis (Web Audio API) tanpa perlu unduh file audio eksternal yang berat.
* [x] Pilihan warna truk (Kuning, Merah, Biru, Hijau).

---

## 🚀 Fase 2: Peningkatan Interaksi & Kerapian (Enhancement)
* [ ] Mode Layar Penuh (Fullscreen) untuk kenyamanan rekam layar YouTube.
* [ ] Variasi muatan: pasir laut, buah-buahan, permen jelly, balok warna.
* [ ] Rintangan jalanan lucu: genangan lumpur yang bikin cipratan air, tanjakan curam.
* [ ] Tombol CTA Affiliate Shopee ("Beli Truk Mainan Nyata").

---

## 🔮 Fase 3: Fitur Masa Depan (Advanced)
* [ ] Kendaraan baru: Excavator pengeruk pasir, Truk Pemadam, Truk Monster.
* [ ] Mode Cuci Truk (Car Wash Mini-game).
* [ ] Sistem penyimpanan koin bintang via LocalStorage.
